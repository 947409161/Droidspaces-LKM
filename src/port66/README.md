# Android 15 / Linux 6.6 port

Independent experimental source set, derived from the 6.12 port and adapted
against the pinned android15-6.6 DDK. Loading is restricted to the matching QEMU
kernel; no device has been validated.

See [ORIGIN](ORIGIN) for source provenance and
[validation notes](../../docs/android15-6.6.md) for build commands and results.
